# 🧮 Mathematics Automation Project

Welcome to my very first GitHub repository! This project features a Python script that automates the calculation of basic mathematical statistics on a custom dataset.

## 🚀 Features
* **Mean:** Calculates the exact average of a dataset.
* **Median:** Finds the precise middle value of the numbers.
* **Mode:** Identifies the most frequent number (handles data errors if no unique mode exists).

## 🛠️ How to Run the Script
1. Make sure you have **Python 3** installed on your computer.
2. Open your terminal or command prompt.
3. Run the following command:
   ```bash
   python math_stats.py
   ```

## 📦 Built-In Libraries Used
* `statistics` — Python's standard library for calculating mathematical stats.
